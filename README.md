# Full Stack Blog Website

A full-stack blog website built using HTML, CSS, JavaScript, Node.js, and Express.js.

## Features

- Add blogs
- View blogs
- Edit blogs
- Delete blogs
- Search blogs
- Blog counter
- REST API
- GitHub and Vercel deployment

<!-- Additionly added -->
## Database Setup

1. Install MySQL
2. Open MySQL Workbench
3. Run database.sql
4. Update db.js with MySQL username/password

Install dependencies:

npm install

Run project:

node server.js
